# 品牌资产

本目录是双端共享的品牌资产，属于机器可读契约，与 `../tokens/design-tokens.json` 和 `../terminology.json` 同级入库。

**所有色值都来自设计令牌，不得在资产或两端代码中出现未登记的颜色。** `palette.json` 记录了「语义名 → 令牌键」的映射，两端代码与 CI 校验都应读它。

## 设计意图

一只正面的熊头剪影：双耳与头是一个连续的实心形状，蜂蜜色吻部压在下方。它要传达的不是「工具」，而是「一个温和、可亲近、能批量跑安卓实例的运行器」。所以形刻意做成圆角、无锐角、左右严格对称，任何尺寸下先读出熊形，再读出细节。

## 资产清单与用途

| 文件 | 用途 | 宽高比 | 最小使用尺寸 |
|---|---|---|---|
| `logo-mark.svg` | 纯图形标识，用于浅色底。窗口标题栏、列表行、About 页、文档页眉 | 1:1 | 16×16 px |
| `logo-mark-inverse.svg` | 纯图形标识反色版，用于深色底 | 1:1 | 16×16 px |
| `logo-horizontal.svg` | 横版标识（图形 + 中英文字），用于浅色底。安装向导、关于对话框、启动页 | 3.125:1 | 96×31 px |
| `logo-horizontal-inverse.svg` | 横版标识反色版，用于深色底 | 3.125:1 | 96×31 px |
| `icon-app.svg` | 方形应用图标，用于窗口图标、任务栏、桌面快捷方式、应用商店 | 1:1 | 16×16 px，上限 256×256 px |
| `palette.json` | 语义名到令牌键的映射、配色方案、对比度实测值 | — | — |

界面窄处一律用纯图形或应用图标，不要压横版：横版在 96 px 宽时副标题只剩约 5 px 高，不可读。

## 最小尺寸与缩放

- **所有资产必须等比缩放**，不得单独拉伸某一方向。
- `logo-mark.svg` 与 `logo-mark-inverse.svg`：16 px 起仅保证轮廓与双耳可辨；**五官在 64 px 以上才清晰**，16–32 px 区间五官会自然隐去，这是预期行为，不是缺陷。
- `icon-app.svg`：16 px 到 256 px 全区间可用。地砖自带留白，缩到 16 px 时仍能读出「绿地砖上的浅色熊」。
- `logo-horizontal.svg` 与反色版：96×31 px 为绝对下限，**推荐 160×51 px 以上**。
- 供 Android 启动器或 Windows 资源管理器使用的位图由两端在构建期从 SVG 渲染，**渲染后不得再手工改色**。

## 留白规则

以资产自身的图形高度为基准，下面的比例都已内置在文件里，不需要调用方再计算：

- **纯图形**：四周留白 ≥ 图形高度的 1/8。空间不足时改用 `icon-app.svg`，它自带地砖，等效于自带留白。
- **应用图标**：地砖内部已留出内边距；地砖外围仍需留白 ≥ 地砖边长的 4%，避免在密集列表中糊成一片。
- **横版**：图形与文字的间距固定为标题字号的 0.77 倍，**不可压缩、不可用负字距把两块拉近**；四周留白 ≥ 标题高度（原始尺寸下 52）的 1/4。
- 留白区内不得出现文字、边框、分割线或其他图标。

## 深浅背景下的使用约束

判定规则：底色接近 `canvas` / `fur-light` 一侧为浅色底，接近 `ink` 一侧为深色底。

1. **浅色底**用 `logo-mark.svg`、`logo-horizontal.svg`。
2. **深色底**用 `logo-mark-inverse.svg`、`logo-horizontal-inverse.svg`。
3. **不要**把 `logo-mark.svg`（小熊棕熊头）直接放在品牌绿 `#2E5C4A` 底上：棕绿对比度只有 2.20:1，轮廓仍能读出但低于图形元素的 3:1 门槛，在小尺寸和低亮度屏幕上会明显发闷。深绿底请用反色版，或者用 `icon-app.svg`（自带地砖）。
4. **禁止**自行替换文字色值来适配背景。需要深色底就用随附的反色版文件，这是两个独立资产而不是一个可调参数。
5. 蜂蜜黄 `#D9A441` 在白底上只有 2.25:1，**不得**用作文字、图标细节或任何小尺寸元素；它只留给界面延展与点缀。
6. 若必须把资产放在第三种底色上，先用 `palette.json` 的 `contrast.ratios` 核对：图形与底色需 ≥ 3:1，正文尺寸的文字需 ≥ 4.5:1。达不到就换底色，不要改资产。

## 配色取值来源

每个色值都对应 `../tokens/design-tokens.json` 中的一个令牌键：

| 语义名 | 令牌键 | 值 | 用在哪 |
|---|---|---|---|
| `bear-brown` | `color.brand.primary` | `#C87533` | 浅色底熊头；各版本吻部与内耳 |
| `forest-green` | `color.brand.secondary` | `#2E5C4A` | 应用图标与横版地砖；反色版五官 |
| `honey-yellow` | `color.brand.accent` | `#D9A441` | 品牌资产未占用，留给界面延展 |
| `fur-light` | `color.surface.raised` | `#F7F4F0` | 反色版与应用图标熊头；反色横版副标题 |
| `ink` | `color.text.primary` | `#1C1917` | 浅色底横版主标题；正色版五官 |
| `ink-soft` | `color.text.secondary` | `#57534E` | 浅色底横版副标题 |
| `on-dark` | `color.text.inverse` | `#FFFFFF` | 反色横版主标题 |
| `canvas` | `color.surface.base` | `#FFFFFF` | 浅色基面，判定浅色底的参照 |

文字的字体族取自 `typography.fontFamily.primary`（`Microsoft YaHei UI, Segoe UI, sans-serif`），字号对应 `typography.size.title` 与 `typography.size.caption`。

**SVG 不引用任何外部字体或图片资源，不内嵌位图**，离线可用。横版的文字以 `<text>` 保留，依赖系统已安装的字体；两端发布渠道若要求字形完全一致，在构建期把文字转曲后再分发，不要手工替换字形。

## 两端引用

Windows 端在 WPF 中把 SVG 转成矢量图形或构建期渲染的位图；Android 端用矢量图资源或构建期渲染的位图。**两端都不得在代码里写字面色值字面量**，一律引用 `palette.json` 的角色名。
