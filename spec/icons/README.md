# 图标集

本目录是双端共享的界面图标，与 `../tokens/design-tokens.json`、`../brand/`、`../terminology.json` 同级入库，属于机器可读契约。

**每个图标都是纯 SVG**：不含 `<script>`、不内嵌 base64 位图、不引用外部字体或图片资源，离线可用。两端在构建期把 SVG 转换为各自的矢量资源或位图，**渲染后不得手工改色**。

## 色值来源

图标的每一个色值都取自 `../tokens/design-tokens.json`，**不得在图标文件或两端代码中出现未登记的颜色**。色值只能在构建期由两端从令牌解析后写入，本目录的 SVG 直接内联令牌取值以保证离线可读。

| 语义名 | 令牌键 | 值 | 用在哪 |
|---|---|---|---|
| `ink` | `color.text.primary` | `#1C1917` | 全部图标的默认描边与填充 |
| `forest-green` | `color.brand.secondary` | `#2E5C4A` | 成功语义、运行态、强调笔画 |
| `warning` | `color.state.warning` | `#B45309` | 暴露级别、宿主环境错误 |
| `danger` | `color.state.danger` | `#B91C1C` | 删除操作、失败态 |

**蜂蜜黄 `color.brand.accent`（`#D9A441`）在白底上对比度只有 2.25:1，本目录一律不使用**，与 `../brand/README.md` 的约束一致。`bear-brown`（`#C87533`）对比度 3.47:1 虽达图形元素门槛，但它是品牌标识的专用色，图标集不占用，以免与 Logo 抢占识别。

**图标是单色前景资产**：一律绘制在浅色底上。放到深色底时由两端把前景替换为 `color.text.inverse`（`#FFFFFF`）或改用该图标集的浅底版本，不得逐个手改文件内的色值。

## 资产清单

全部图标统一 `viewBox="0 0 24 24"`，宽高比 1:1，**最小使用尺寸 16×16 px**，向上等比缩放，不单独拉伸某一方向。

### 实例与镜像生命周期

| 文件 | 用途 | 适用场景 |
|---|---|---|
| `instance.svg` | 实例 | 实例列表行、新建向导的实例选择器、列表分组标题 |
| `image.svg` | 镜像 | 镜像管理列表、实例编辑器选用镜像下拉框 |
| `start.svg` | 启动 | 实例列表行操作按钮、启动确认对话框 |
| `stop.svg` | 停止 | 实例列表行操作按钮；仅在运行态可点 |
| `delete.svg` | 删除 | 实例列表行操作按钮、删除二次确认对话框 |

### 快照与多开

| 文件 | 用途 | 适用场景 |
|---|---|---|
| `snapshot.svg` | 创建快照 | 实例列表行操作按钮，快照创建入口 |
| `restore.svg` | 恢复 | 快照列表行的恢复动作；恢复即切换磁盘链顶层，不可逆，须二次确认 |
| `multi-instance.svg` | 多开 | 多开视图切换、并行实例数量展示 |

### 交互与传输

| 文件 | 用途 | 适用场景 |
|---|---|---|
| `projection.svg` | 投屏 | 投屏窗口入口。**投屏只负责看**，不承担操控 |
| `input-channel.svg` | 输入通道 | 输入通道状态展示：当前生效的是原生输入还是投屏，两条都不通时明确标出 |
| `file-transfer.svg` | 文件传输 | 宿主与实例之间的双向文件复制入口 |

### 状态

状态图标用于实例列表的状态列，**只表示状态，不表示原因**。

| 文件 | 用途 | 适用场景 |
|---|---|---|
| `state-stopped.svg` | 停止态 | 实例已停止且数据保留 |
| `state-running.svg` | 运行态 | 实例正在运行 |
| `state-failed.svg` | 失败态 | 实例已进入 `failed`。失败不自动销毁数据，须保留现场 |

### 能力与风险

| 文件 | 用途 | 适用场景 |
|---|---|---|
| `fidelity.svg` | 保真度 | 保真度六项逐项结论展示。未通过的项不得用本图标 |
| `device-identity.svg` | 设备标识 | 每实例独立设备标识的展示与状态说明；标识不得自动复用 |
| `exposure.svg` | 暴露级别 | 端口对外可达范围的三级展示。选 `public` 时必须显式警示 |
| `diagnostics.svg` | 诊断包 | 一键导出诊断包的入口。导出前须让用户预览将包含的内容 |
| `error-environment.svg` | 宿主环境错误 | 虚拟化组件缺失或未启用等宿主前提不满足。**必须在启动前拦截并给出修复指引** |

## 命名与语义边界

- 文件名与 `../terminology.json` 的术语 `id` 一一对应，术语表新增概念时图标集同步补齐，删除术语时对应图标一并移除。
- **`state-*` 前缀是状态，`error-*` 前缀是错误分类**：状态回答「现在怎么样」，错误分类回答「为什么不行」。二者不得互相替代，`state-failed.svg` 不能代替 `error-environment.svg`。
- 图标承担不了错误分类的区分度。宿主环境错误、虚拟化实现错误、实例内错误、配置错误四类共用的图形语言只有色彩与一个图标，**错误类别必须靠文案说明，不得靠图标区分**。

## 两端引用

Windows 端在 WPF 中把 SVG 转成矢量图形或构建期渲染的位图；Android 端用矢量图资源或构建期渲染的位图。**两端都不得在代码里写死面色值字面量**，一律从 `../tokens/design-tokens.json` 解析。
